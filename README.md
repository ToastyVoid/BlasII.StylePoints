# Miracle May Cry
A mod adding style points and a style meter to Blasphemous II, giving you a better reason to style on those penitents, by swapping weapons and making combos.

## Ratings

| Rank | Name           | Color  | Points |
| ---- | -------------- | ------ | ------ |
| SSS  | Blasphemous II | red    |   2000 |
| SS   | Blasphemous    | red    |   1000 |
| S    | Sacreligious   | red    |    500 |
| A    | Apostate       | orange |    300 |
| B    | Blasphem       | yellow |    150 |
| C    | Corrupt        | green  |     50 |
| D    | Descrator      | cyan   |      1 |

## Keybindings

| Key  | Action                                     |
| ---- | ------------------------------------------ |
| `F8` | Toggle on/off the mod's debug information. |

## Dependencies

- [Modding API](https://github.come/BrandenEK/BlasII.ModdingAPI)
